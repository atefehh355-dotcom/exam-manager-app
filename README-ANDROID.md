# گرفتن فایل APK اپ «مدیریت آزمون‌ها»

اینجا دو تا راه هست. **راه اول رو پیشنهاد می‌کنم** چون نیازی به نصب
Android Studio یا SDK اندروید نداره؛ فقط یه کامپیوتر با اینترنت و
یه حساب رایگان گیت‌هاب لازمه.

---

## راه اول (پیشنهادی): گیت‌هاب خودش APK رو بسازه

توی این پوشه یه فایل هست به اسم
`.github/workflows/build-apk.yml`. این فایل به گیت‌هاب می‌گه: «هر وقت
این پروژه رو گرفتی، خودت یه ربات روشن کن، اپ رو بساز، و در آخر یه
فایل APK آماده بده که بشه دانلودش کرد». خودت هیچ برنامه‌ای نصب
نمی‌کنی — همه‌چیز روی سرورهای گیت‌هاب انجام می‌شه.

### قدم‌به‌قدم

1. **نصب Node.js** (فقط یه بار، مثل نصب هر برنامه‌ی دیگه):
   از [nodejs.org](https://nodejs.org) نسخه‌ی «LTS» رو دانلود و نصب کن.

2. **ساخت پوشه‌ی اندروید روی کامپیوتر خودت** (چون این کار به اینترنت
   نیاز داره و اینجا برام ممکن نبود):
   - همین پوشه (`android-project`) رو باز کن.
   - یک ترمینال/CMD توی همین پوشه باز کن.
   - این دو دستور رو یکی‌یکی بزن:
     ```bash
     npm install
     npx cap add android
     ```
   - حالا یه پوشه‌ی جدید به اسم `android` کنار بقیه فایل‌ها ساخته
     می‌شه.

3. **گرفتن فایل `google-services.json`:**
   - برو به [کنسول Firebase پروژه‌ت](https://console.firebase.google.com/project/exam-2bfe7/settings/general).
   - «Add app» → آیکون اندروید.
   - Package name رو دقیقاً `ir.rezah.exammanager` بذار (همونی که
     توی `capacitor.config.json` نوشته شده).
   - فایل `google-services.json` رو دانلود کن و بذارش داخل
     `android-project/android/app/google-services.json`.

4. **ساخت یه حساب رایگان گیت‌هاب** (اگه نداری): [github.com](https://github.com)

5. **ساخت یه ریپوی جدید و آپلود پوشه:**
   - توی گیت‌هاب، روی «New repository» بزن، یه اسم بذار (مثلاً
     `exam-manager-app`)، «Create» بزن.
   - توی صفحه‌ی ریپوی خالی، روی لینک «uploading an existing file»
     بزن.
   - کل محتویات پوشه‌ی `android-project` (همه‌ی فایل‌ها و پوشه‌ها،
     از جمله پوشه‌ی `android` که تازه ساختی و پوشه‌ی مخفی `.github`)
     رو بکش و بنداز توی اون صفحه، بعد «Commit changes» بزن.
     > نکته: پوشه‌ی مخفی `.github` ممکنه توی File Explorer دیده نشه؛
     > اگه دیدیش که خوبه، اگه ندیدیش، تنظیمات Explorer رو روی
     > «نمایش فایل‌های مخفی» بذار.

6. **صبر کن ربات کارش رو بکنه:**
   - توی صفحه‌ی ریپو، برو تب **Actions**.
   - یه اجرا می‌بینی که در حال اجراست (دایره‌ی زرد چرخان). چند
     دقیقه صبر کن تا تیک سبز بخوره.
   - اگه ضربدر قرمز خورد، روی اون اجرا کلیک کن و ببین کدوم مرحله
     خطا داده (معمولاً یعنی `google-services.json` رو درست نذاشتی).

7. **دانلود APK:**
   - روی همون اجرای موفق (تیک سبز) کلیک کن.
   - پایین صفحه، بخش **Artifacts**، یه فایل به اسم
     `exam-manager-debug-apk` هست — دانلودش کن (یه zip می‌گیری که
     داخلش `app-debug.apk` هست).

### نصب روی گوشی
1. فایل `app-debug.apk` رو با کابل، تلگرام (به خودت)، گوگل‌درایو یا
   هر روشی به گوشیت منتقل کن.
2. روی فایل apk بزن. اگه گوشی گفت «از منابع ناشناس نصب نکن»، برو
   تنظیمات → و اجازه‌ی نصب از همون منبع (مرورگر/فایل‌منیجر/تلگرام)
   رو فعال کن.
3. نصب کن و باز کن.

## راه دوم: نصب محلی با Android Studio

اگه ترجیح می‌دی همه‌چیز روی کامپیوتر خودت باشه (بدون گیت‌هاب)،
همون مراحل قدیمی رو دنبال کن:

1. Node.js رو نصب کن.
2. `npm install`
3. `npx cap add android`
4. همون‌طور که بالا گفته شد، `google-services.json` رو بذار.
5. برای گرفتن SHA-1 (لازم برای ورود با گوگل):
   ```bash
   cd android
   ./gradlew signingReport
   ```
   خط `SHA1` مربوط به `debug` رو کپی کن و در Firebase Console →
   Project settings → پایین صفحه، «Add fingerprint» وارد کن.
6. `npm run sync`
7. `npm run open:android` (یا مستقیم پوشه‌ی `android` رو با
   Android Studio باز کن).
8. یه گوشی/شبیه‌ساز با Google Play وصل کن و Run بزن.
9. برای فایل نهایی: از منوی Android Studio →
   **Build → Generate Signed Bundle / APK**.

## نکات مهم (هر دو راه)

- فایل‌های `icon.jpg`، `timer.html` و `Mikhak-Regular.woff2` رو باید
  خودت داخل پوشه‌ی `www/` (کنار `index.html`) بذاری؛ اینا رو برام
  نفرستاده بودی.
- نسخه‌ای که این‌جا ساخته می‌شه یه **APK دیباگ** (debug) هست — برای
  نصب روی گوشی خودت یا تست کافیه، ولی برای انتشار در Google Play باید
  یه نسخه‌ی امضاشده‌ی release بسازی (مرحله‌ی جدا، اگه بهش رسیدی بگو
  راهنماییت کنم).
- من این مسیر رو اینجا (بدون اینترنت و بدون Android SDK) نتونستم واقعاً
  اجرا و تست کنم؛ اگه لاگ خطای Actions یا Android Studio رو برام
  بفرستی، دقیق‌تر کمکت می‌کنم رفعش کنیم.
